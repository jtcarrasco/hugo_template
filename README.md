# Hugo Template

A Hugo static site scaffold with minimal layouts and demo content.

## Quick Start

```bash
hugo server -D
```

Open http://localhost:1313

## Requirements

- Hugo extended (latest) — install via https://gohugo.io/installation/

## Demo Content

- Home page
- Blog at `/posts/`
- About at `/about/`
- Two sample posts

## Build

```bash
hugo build   # outputs to public/
```
